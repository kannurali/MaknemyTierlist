# Чат-менеджер, этап 2: активность

Дата: 2026-11-08. Основа — этап 1 (модерация,
`docs/superpowers/specs/2026-11-07-chat-manager-moderation-design.md`, PR #222).
Ветка `feat/chat-manager-activity` отрезана от `feat/chat-manager-moderation`.

## Что входит

Статистика сообщений и топы, анкета и профиль участника, репутация,
награды. Всё работает в любой группе с ботом, только по-русски, на том же
модуле `public_html/api/lib/cm/`.

Решения (владелец сказал «делай все этапы», решения приняты по образцу
«Ириса» и правилам этапа 1):

- Статистика и репутация — свои в каждом чате. Анкета (пол, город, день
  рождения, «о себе») — одна на человека для всех чатов: её заполняют один раз.
- Бот ничего не делает сам. Всё — по командам участников; модератор может
  выключить любой раздел через `дк <раздел> 6`.
- Статистика считается с момента, когда бот появился в чате; прошлую
  переписку Telegram боту не отдаёт.
- Графиков нет, только текст.

Не входит: графики, закладки и чатбук, поздравления с днём рождения,
глобальная репутация между чатами, отдельные «награждающие» (их заменяет
`дк награды N`).

## Встраивание в этап 1

- Новые файлы: `api/lib/cm/stats.php`, `profile.php`, `rep.php`,
  `awards.php`; подключаются в `api/lib/cm/cm.php` после `'timers'` и до `'router'`.
- Команды дописываются в `CM_COMMANDS` (`parse.php`), тексты — в `CM_TEXTS`
  (`texts.php`), разделы — в `CM_SECTIONS` (`ranks.php`): `статистика`,
  `репутация`, `награды`, `анкета`.
- Новые ключи настроек нужно добавить в `CM_DEFAULTS` (`db.php`), иначе
  `cm_settings()` их отбросит. В этом этапе новых ключей нет.
- `router.php`, `cm_on_message`: после `cm_msg_log` — `cm_stats_hit()` (+1
  сообщение автору за сегодня). Правки не считаются. До команд, после
  проверки спамера — спамера не считаем.
- `router.php`: перед поиском команды — `cm_rep_try()` (ответ «+» / «-» /
  «спасибо», см. ниже). Если это было голосование — сообщение дальше не идёт.
- `cm_cmd_whoami` («кто я») теперь показывает профиль — тот же, что
  «профиль». Его текст собирает `cm_profile_lines()` в `profile.php`: этап 3
  допишет туда строки о браке, паре и клане.
- Одна миграция `docs/migrations/2026-11-08-chat-manager-activity.sql`, те же
  таблицы для SQLite — в `tests/cm_schema.php` (дописать в `cm_sqlite_tables`).
  Порядок на бою: сначала миграция этапа 1, потом эта.

| Таблица | Поля | Зачем |
| --- | --- | --- |
| `cm_stats` | (`chat_id`, `user_id`, `day`) PK, `msgs`; ключ (`chat_id`, `day`) | сообщения за день; `day` — дата по Москве числом `YYYYMMDD` |
| `cm_profiles` | `user_id` PK, `gender` (`''`/`m`/`f`), `city`, `birthday` (`ДД.ММ` или `ДД.ММ.ГГГГ`), `about`, `updated_at` | анкета, общая для всех чатов |

| `cm_awards` | `id`, `chat_id`, `user_id`, `level` (1–8), `reason`, `by_id`, `created_at`, `until_at` (0 — навсегда), `removed_at` (0 — действует); ключ (`chat_id`, `user_id`) | награды |

Счётчик сообщений: `UPDATE cm_stats SET msgs = msgs + 1 WHERE …`, ноль строк
— `INSERT` в `try/catch` (как остальной модуль: без `ON DUPLICATE KEY`).

## Команды

Префикс `! . /` необязателен. Правила этапа 1 те же: команды уровня 0 без
префикса — только ровно команда, без лишних слов, если у команды нет
аргументов по смыслу; с целью — только если цель нашлась.

| Раздел (ключ для `дк`) | Команды | Ранг |
| --- | --- | --- |
| Статистика (`статистика`) | `стата`, `стата 20`, `стата неделя`, `стата 15 месяц`, `стата всё` | 0 |
| | `моя стата` (или ответом / `@ник` — чужая) | 0 |
| Анкета (`анкета`) | `профиль` / `кто я` / `кто ты` (ответом или `@ник`) | 0 |
| | `+пол м\|ж`, `+город Москва`, `+др 25.12` или `+др 25.12.2005`, `+о себе текст`; `-пол`, `-город`, `-др`, `-о себе` | 0, только себе |
| Репутация (`репутация`) | ответ `+`, `спасибо`, `спс`, `благодарю` → +1; ответ `-` → −1; `+реп` / `-реп` (ответом или `@ник`) | 0 |
| | `репа` (своя; ответом / `@ник` — чужая), `топ репы` | 0 |
| Награды (`награды`) | `+награда 3 @ник причина`, `+награда 5 @ник на 30 дней причина`, `-награда 12` (по номеру) | 3 |
| | `награды` (свои; ответом / `@ник` — чужие) | 0 |

### Статистика

- Период: `день` (по умолчанию, сегодня по Москве), `неделя` (7 дней,
  сегодня включительно), `месяц` (30 дней), `всё`. Число — сколько мест
  показать, 1–50, по умолчанию 10.
- Выдача: «📊 Активность за неделю (всего 1 234):», дальше строки
  «1. Вася — 120». Покинувшие чат (`left_at` > 0) в топ не попадают.
- `моя стата`: сообщения за день / неделю / месяц / всё и место в топе за всё
  время.

### Анкета и профиль

Профиль — одно сообщение:

```
👤 Вася Пупкин
Ранг: 2 — старший модератор
Сообщений: 1 234 (сегодня 15), место 3
В чате с: 07.11.2026
Репутация: 15
Награды: 🥇 Лучший трейдер, 🏅 Помощь новичкам
Варны: 1/3
Пол: мужской · Город: Москва · День рождения: 25.12
О себе: …
```

- Пустые строки анкеты не выводятся.
- «В чате с» — первый день в `cm_stats` этого чата. Строк нет — строка не
  выводится.
- Награды: действующие, по убыванию степени, не больше пяти, дальше «и ещё N».
- `+др`: дата проверяется (`checkdate`), год — от 1900 до текущего.
- `+о себе` — до 200 символов, `+город` — до 64, только простой текст.
- Анкету меняет только её хозяин (цель не принимается).

### Репутация

- Голос «+»/«-»: сообщение — ответ на чужое сообщение, и вся его первая строка
  ровно `+`, `-`, `спасибо`, `спс` или `благодарю` (регистр и `!` неважны).
  Иначе это обычное сообщение.
- Нельзя себе и ботам.
- Один голос одному и тому же человеку — раз в 24 часа. Всего — не больше 20
  голосов в сутки от одного человека в чате. Лишний голос — молча: это ответ
  в живом разговоре, ругаться на него не нужно. С командой `+реп` при отказе
  бот поясняет, в чём дело.
- Ответ бота — временный (автоудаление этапа 1): «👍 Вася → Петя: +1
  (репутация 15)».
- `топ репы` — 10 лучших в чате с ненулевой репутацией.

### Награды

- Степени 1–8: 🎗 🏅 🥉 🥈 🥇 🎖 🏆 👑.
- Причина обязательна, до 100 символов. Срок необязателен: «на 30 дней»
  разбирается `cm_take_term`; без срока — навсегда.
- Не больше 20 действующих наград у человека в чате.
- `-награда N` снимает (`removed_at`); снять может тот же ранг, что выдать.
- Выдача — постоянное сообщение: «🥇 Петя получает награду 5-й степени:
  Лучший трейдер».

## Ошибки и пределы

- Нет таблиц этапа 2 → эти команды отвечают «ещё не настроено» (`cm_ready2()`
  проверяет `cm_stats`), счётчик сообщений молча пропускается. Модерация
  работает как раньше.
- Все ответы идут через бюджет сообщений этапа 1 (15 в минуту на группу).
- Ответы на голоса репутации и подсказки — временные, топы и профиль —
  постоянные.
