# Значок «Перерассмотр цены» на карточке предмета

**Дата:** 2026-09-17
**Ветка:** `fix/trend-swap-size`

## Задача

Значок тренда «Перерассмотр цены» (`trend-swap.svg`) на карточке в тире
слишком мелкий.

## Причина

- **Компьютер.** Все значки тренда на карточке одной ширины, `1.27cqw`. У
  стрелок холст 27×32, у перерассмотра 37×43, и рисунок сложнее: круглые
  стрелки при той же ширине читаются мельче. В легенде значок в 37/27 раза
  шире стрелок (`3.43cqw` против `2.51cqw`), на карточке — нет.
- **Телефон — ошибка.** Десктопное `.cell .trend.tr-swap { width: 1.27cqw; }`
  специфичнее телефонного `.cell .trend { width: 2.5cqw; }`, и значок на
  телефоне остаётся вдвое меньше соседних стрелок.

## Решение владельца

Из показанных на живом тирлисте размеров (сейчас, ×1,37, ×1,65, ×1,97)
выбран **×1,37 — как в легенде**.

## Правила (`styles.css`)

| Где | Правило |
|---|---|
| компьютер | `.cell .trend.tr-swap { width: 1.74cqw; top: 3.46cqw; }` (было `width: 1.27cqw`) |
| телефон, ≤640px | `.cell .trend.tr-swap { width: 3.43cqw; top: 6.58cqw; }` — новая строка сразу после `.cell .trend { width: 2.5cqw; }` |

- Ширина = ширина стрелки × 37/27: `1.27 × 37/27 = 1.74`,
  `2.5 × 37/27 = 3.43`.
- Верх подобран так, чтобы низ значка совпал с низом стрелок и значок не
  наезжал на цену: низ стрелки = `top + ширина × 32/27`, низ перерассмотра =
  `top + ширина × 43/37`. Компьютер: `3.98 + 1.505 = 5.485`,
  `3.46 + 2.022 = 5.482`. Телефон: `7.6 + 2.963 = 10.563`,
  `6.58 + 3.986 = 10.566`.
- Телефонная строка той же специфичности, что десктопная, и стоит ниже в
  файле — поэтому на телефоне действует она.
- `left` не меняется (`.1cqw`): значок растёт вправо и вверх, над иконкой.

## Чего не трогаем

Легенда, кнопка в окне редактирования (`.seg .trend.tr-swap`), общие
`.trend.tr-swap` для легенды. PNG отдельно не трогаем: экспорт рисует
вёрстку как есть, значок в нём будет того же размера, что на сайте.

## Проверка

- `tests/tags_test.php`, тест «значки тренда в ячейке»: обе строки на месте,
  телефонная — после `.cell .trend { width: 2.5cqw; }`, ширина в 37/27 раза
  больше стрелки (±0,01), низ на уровне стрелки (±0,02cqw) — на компьютере
  и на телефоне.
- Замер в Playwright (компьютер 1440, телефон 390): отношение ширин
  перерассмотра и стрелки ≈ 1,37, низ перерассмотра на уровне низа стрелки
  (±1px), низ значка выше верха полосы с ценой.
- `styles.css?v=` 58 → 59.
