# Главная страница с вступительной анимацией

Дата: 2026-08-28
Источник: Figma «MAKNEMY (Copy)», `nytiYkHJOlt31iifMkuB0A`, ноды `4:456` («главная 1 слайд») и `102:373` («главная 2 слайд»).

## Задача

Сверстать главную страницу сайта по макету и повторить вступительную анимацию,
заданную в Figma как прототип-переход между двумя слайдами.

До этой работы главной страницы в проекте не существовало: на `/` жил тирлист,
рядом были `news.php` и админка.

## Что такое «два слайда»

Это не две картинки, а два состояния одной страницы. Слайд 1 — стартовое
положение, слайд 2 — конечное. Переход описан в прототипе:

```
главная 1 слайд --[AFTER_TIMEOUT 0.8s]--> главная 2 слайд
transition: SMART_ANIMATE, easing EASE_OUT, duration 1.0s
```

То есть анимация играет один раз при загрузке: 0.8 с пауза, потом 1 с элементы
съезжаются из-за краёв экрана в свои финальные позиции.

**Известная плата за переезд.** Тирлист проиндексирован поисковиками как `/`.
После переезда `/` остаётся живым URL, но с другим содержимым, поэтому 301 тут
неприменим, и накопленный вес страницы тирлист теряет. У `index.php` меняются
`canonical` и `og:url`, в `sitemap.xml` добавляется `/tierlist`. Просадка позиций
тирлиста на несколько недель ожидаема и принята заказчиком осознанно.

## Единица масштаба

Как в `topbar.css`:

```css
--u: min(1px, calc(100vw / 1443));
```

Вся геометрия макета пишется как `calc(N * var(--u))`. Шире 1443px страница
фиксируется на макетных значениях, уже — сжимается пропорционально. Ниже 900px
включается отдельная раскладка (не сжатие): лид в одну колонку, карточки в
горизонтальный скролл, тяжёлый декор скрыт.

## Анимация

Общие параметры для всех летящих слоёв:

```css
animation-duration: 1s;
animation-delay: .8s;
animation-fill-mode: both;
animation-timing-function: cubic-bezier(0, 0, .58, 1); /* Figma EASE_OUT */
```

Каждый `@keyframes` задаёт только `from`; `to` — родная позиция элемента.
Анимируется исключительно `transform` (и `opacity` в одном случае), поэтому
работа уходит на композитор и не вызывает пересчёта раскладки.

Дельты сняты как «позиция в слайде 1 минус позиция в слайде 2», в единицах
макета:

| слой | `from` |
| --- | --- |
| `сакура 2` (слева) | `translateX(-199px)` |
| `сакура 1` (справа) | `translateX(301px)` |
| `iPhone` мокап | `translateX(473px)` |
| `Ellipse 1` (круг) | `translateX(518px)` |
| `Rectangle 20` (квадрат) | `translateX(318px)` |
| `Rectangle 21` (квадрат малый) | `translateX(-537px)` |
| `Polygon 1` (треугольник) | `translateX(-627px)` |
| `MAKNEMY` декор, ряд y=10 | `translateX(-621px)` |
| `MAKNEMY` декор, ряд y=163 | `opacity: 0` |
| `.cards` (контейнер) | `translateY(476px)` |
| карточка внутри `.cards` | `translateX(160px)` |

У элементов с собственным поворотом (`Rectangle 20`, `Rectangle 21`,
`Polygon 1`, `сакура 2`, мокап) поворот входит в ту же `transform`-цепочку
перед сдвигом, иначе анимация будет крутить элемент вокруг чужой оси.

Двухуровневость карточек сохранена как в макете: контейнер едет вверх, дети —
влево. Суммарно карточка стартует со сдвига `(160px, 476px)`, но каждый уровень
правится отдельно и сверяется с макетом.

### Отступление от макета: бегущая строка

Лента `Component 2` («самые точные цены • постоянные розыгрыши • калькулятор цен
• свежие новости») описана в Figma как `SMART_ANIMATE 8s, EASE_OUT_BACK` — но
это разовая подмена варианта компонента, а содержимое ленты продублировано
дважды с шагом 1878px, то есть задумано бесконечным.

`ease-out-back` на бесконечном цикле даёт рывок и откат назад на стыке петли.
Реализуется как `linear infinite 8s` со сдвигом на 1878px — это то, что макет
изображает, просто корректно зациклено.

### Доступность

```css
@media (prefers-reduced-motion: reduce) { /* animation: none, финальные позиции */ }
```

## Стеклянные плашки

Декоративные фигуры и панель лида используют в макете эффект `GLASS`
(заливка `rgba(217,217,217,.2)` плюс размытие подложки). На вебе это
`backdrop-filter: blur()`.

`backdrop-filter` включается только шире 900px. На телефонах остаётся плоская
заливка без размытия: размытие подложки на мобильных GPU стоит дорого, а проект
уже ловил падения iPhone на тяжёлых композитных слоях (см. решение об отказе от
`mix-blend-mode` на сцене тирлиста).
