# Nexus Tier List — редактор

Интерактивный редактор тир-листа по Blox Fruits в стиле макета **Nexus Tier List (сакура)**.
Чистый HTML/CSS/JS, без сборки.

## Как запустить

**Просто дважды кликните `start.bat`** — он поднимет локальный сервер и откроет редактор в браузере
(нужен установленный Python; адрес: http://127.0.0.1:8780/).

> Можно открыть и `index.html` напрямую двойным кликом — редактор работает,
> но кнопка **«Скачать PNG»** при открытии файлом (`file://`) не сработает:
> браузер блокирует экспорт картинок. Поэтому для скачивания используйте `start.bat`.

Альтернатива без `.bat` (в папке проекта):
```
python -m http.server 8780
```
и открыть http://127.0.0.1:8780/

## Возможности

- **Дорожки как в макете**: плашка тира с полутоновыми точками и логотипом по центру,
  дорожка предметов с текстурой, тёмная полоса под ценами, цветные бейджи типов.
- **Тиры**: добавить (`＋ Тир`), переименовать (клик по названию), свой логотип тира (🖼),
  переместить ▲▼, удалить ✕.
- **Предметы**: добавить (`＋` в тире или `＋ Предмет`), перетаскивать между тирами (drag-and-drop).
- **Автосортировка по цене**: при изменении цены предмет сам встаёт на своё место
  (по убыванию, может перейти в другой тир). Выключается тумблером «Автосорт».
  Кнопка «⇅ Сортировать» сортирует все тиры по убыванию цены.
- **Фильтры**: Фрукты / Пермы / Пассы / Скины — можно включать в любых сочетаниях,
  «Все» возвращает всё. Скрытые предметы не попадают в PNG.
- **Язык интерфейса RU / EN** — тумблер в панели. Переводится только интерфейс:
  названия тиров и предметов, реклама, титры и ссылки идут из БД как есть.
  Легенда лежит внутри тирлиста, поэтому **скачанный PNG выходит на выбранном
  языке**. Выбор запоминается; у нового гостя язык берётся из настроек браузера.
  Строки — в `js/i18n.js`, узлы помечены `data-i18n*` в разметке.
- **Редактирование предмета** (клик по ячейке): название, значение, тип (F/S/M/P/GP/CR),
  спрос (🟢🟡🟠🔴), тренд (↑ ⇄ ↓), своя иконка.
- **Логотип в шапке** — фиксированная картинка (флейм БФ + GLH + MK из макета),
  зашит в сайт и не редактируется — знак авторства на каждом экспорте.
- **Реклама** — карусель в середине тирлиста, всплывающее окно через 12 секунд
  после захода и два боковых борта на широком десктопе. Кампании живут отдельно
  от тирлиста (`/api/promo.php`, таблица `promo`) и настраиваются на странице
  `/admin/promo`. Подробности — в разделе «Реклама» ниже.
- **Команда** — список ролей внизу (Автор, Дизайнер, Аналитик, Помощник аналитика, Кодер сайта).
  Роли и имена редактируются, участников можно добавлять (＋) и убирать (✕).
- **Дата** и тексты редактируются прямо на макете (в режиме редактирования).
- **Режим «Редактирование»** — выключите тумблер, чтобы увидеть чистый вид.
- **Скачать PNG** — сохраняет тир-лист картинкой.
- **Экспорт / Импорт** — сохранить/загрузить весь тир-лист как `.json`.
- **Автосохранение** в браузере (localStorage). **Сброс** — вернуть стандартный шаблон.

зато сломало бы откат, если новый вид не зайдёт.

## Админка

Всё редактирование живёт на отдельных адресах. На публичной странице нет ни
кнопки входа, ни ссылки на панель — тулбар редактирования в `index.html` лежит,
но его группы скрыты, и `app.js` даже не спрашивает роль у сервера.

| Адрес | Что это |
|---|---|
| `/admin` | редактор тирлиста — тот же постер, что на сайте, плюс тулбар |
| `/admin/promo` | панель рекламы |
| `/admin/logout` | выход, только POST из шапки |

Пароль спрашивает **сервер, до отдачи разметки**: гость получает форму входа, а
не страницу редактора с оверлеем. Пароль тот же и та же блокировка после пяти
промахов — форма ходит в `/api/login.php`. Кука ставится на `/`, поэтому вход
один на обе панели.

Разметка постера не продублирована: `admin.php` читает `index.html` и дописывает
к нему шапку, `window.NX_ADMIN_PAGE` и свою таблицу стилей, попутно вырезая
Метрику. Копия разъехалась бы с оригиналом на первой же правке вёрстки.

Адрес `/admin` **без завершающего слэша** (его снимает 301 в `.htaccess`) — это
не косметика. Относительные пути внутри `index.html` и `app.js`
(`assets/dot-green.png`, `js/html2canvas.min.js`) считаются от адреса документа:
на `/admin` они разрешаются от корня, на `/admin/` уехали бы в `/admin/assets/`
и вернули бы 404.

Прежний адрес панели рекламы `/promo-admin.html` редиректит на `/admin/promo`.
Правило стоит в `.htaccess` до отдачи файлов, поэтому работает и на боевом
сервере, где старый файл ещё лежит: деплой копирует поверх и ничего не удаляет.

## Реклама

Три места: **карусель** в середине постера (`strip`), **боковые борта** (`rail`,
только десктоп от 1460×760) и **всплывающее окно** через 12 секунд после захода
(`popup`). Статика и анимация (WebP/GIF) смешиваются свободно.

| Файл | Что делает |
|---|---|
| `js/promo.js` | расписание, взвешенная ротация, частотный лимит окна. Без DOM — тестируется в node |
| `api/promo.php` | хранение кампаний, отдельная таблица `promo`, свой `rev` |
| `admin-promo.php` + `js/promo-admin.js` | панель `/admin/promo`: список кампаний, загрузка макетов, предпросмотр |
| `docs/mediakit/` | коммерческое предложение рекламодателю: места, пакеты, спецификация, собранный PDF. **Вне `public_html`** — на сайт не публикуется, файл отдаётся клиенту напрямую. **Цены — заглушки**, правятся в блоке `PRICES` в конце `mediakit.html` |

**Кампании принципиально не лежат в `state`.** Причины записаны в шапке
`api/promo.php`: всё, что попадает в блоб тирлиста, проходит через
`save_image_bytes()` и ужимается до 256 px; сохранение блоба работает по
принципу «последний записал — тот и прав»; а сам блоб отдаётся с годовым
immutable-кэшем, и смена баннера заставляла бы каждого посетителя качать
тирлист заново.

Файл называется `promo.js`, а не `ads.js`, классы — `ptn-*`, а не `ad-*`:
`##.ad-block` и `/js/ads.js` — стандартные правила блокировщиков рекламы.

Новая таблица заводится тем же `schema.sql`. Пока он не прогнан, сайт работает:
`promo_load()` и `state.php` читают отсутствие таблицы как «кампаний нет».

Локальный показ без PHP (файлы в `.gitignore`, на боевой сайт не уезжают):

```
__seed.local.html     кладёт снимок боевой базы в localStorage
__promo.local.html    кладёт демо-кампании и открывает сайт
```

## Размер иконок

Иконки предметов хранятся с длинной стороной не больше **256 px**
(`ICON_MAX_SIDE` в `api/lib/images.php`). Порог не косметический: на экране
иконка занимает максимум ~130 device-px, а Safari держит в памяти
**распакованный** битмап целиком. Исходники по 800×800 давали 63 МБ битмапов на
полный тирлист — вкладка начинала выбрасывать декодированные картинки, и
иконки пропадали прямо во время прокрутки.

Сжатие применяется при загрузке автоматически. Картинки, загруженные раньше,
переводятся разово:

```
php tools/downscale-images.php --dry-run   # только отчёт
php tools/downscale-images.php             # сжать и перепривязать
```

На боевом хостинге `config.php` лежит над веб-рутом, вне клона репозитория,
поэтому туда нужно указать путь явно:

```
php tools/downscale-images.php --config=/home/maknemyt/config.php --dry-run
```

## Тесты

```
bash tests/run_all.sh
```

PHP-тесты покрывают API, node-тесты (`tests/*_test.mjs`) — словарь интерфейса,
язык описаний, марки полос тиров и логику показа рекламы. Если node не
установлен, его часть пропускается с явным предупреждением.

`tests/images_test.php` и `tests/creatives_test.php` требуют GD. В XAMPP
расширение выключено в `php.ini`, и без него эти тесты дают ложные падения.
`run_all.sh` берёт бинарник из `$PHP` **одним словом**, поэтому флаг в
переменную не запихнуть — нужна обёртка:

```
printf '#!/usr/bin/env bash\nexec /c/xampp/php/php.exe -d extension=gd "$@"\n' > /tmp/php-gd.sh
chmod +x /tmp/php-gd.sh
PHP=/tmp/php-gd.sh bash tests/run_all.sh
```
